# ФОРМАТикс

Браузерный сервис для подготовки лабораторных работ в формате DOCX по базовым требованиям ГОСТ. Все документы обрабатываются **локально в браузере**: файлы не отправляются на сервер.

## Возможности

1. Пользователь сначала загружает DOCX с титульным листом, затем DOCX с текстом работы.
2. Титульный лист сохраняется, а текст работы начинается с новой страницы сразу после него.
3. Для текста работы применяются:
   - Times New Roman, 14 pt, чёрный цвет;
   - выравнивание по ширине;
   - межстрочный интервал 1,5;
   - отступ первой строки 1,25 см.
4. Таблицы получают Times New Roman 14 pt и видимые сплошные границы. Для текста в таблицах не устанавливается отступ первой строки.
5. Рисунки и подписи вида `Рисунок 1` или `Рис. 1` центрируются и не получают отступ первой строки.
6. Нумерованные списки, маркеры и пользовательские стили маркеров переносятся вместе с настройками нумерации из исходного DOCX.
7. Встроенные изображения переносятся в итоговый DOCX вместе с необходимыми связями.

## Запуск

Проект не требует сборки фронтенда и может быть открыт как статический сайт.

### Вариант 1: открыть файл

Откройте `index.html` в современном браузере.

### Вариант 2: локальный сервер

```bash
npm run dev
```

После этого откройте [http://localhost:4173](http://localhost:4173).

## Использование

1. Нажмите **«Начать оформление»**.
2. В первом поле выберите готовый титульный лист в формате `.docx`.
3. Во втором поле выберите DOCX с текстом лабораторной работы.
4. Нажмите **«Оформить и скачать»**.
5. Браузер скачает файл с суффиксом `_ГОСТ.docx`.

## Проверка исходного кода

```bash
npm run build
```

Команда выполняет синтаксическую проверку JavaScript.

## Технические детали

Для чтения и записи DOCX используется [JSZip](https://stuk.github.io/jszip/), который загружается только при создании итогового документа. DOCX является ZIP-архивом с XML-файлами; приложение объединяет основной документ, настройки нумерации и части изображений на стороне клиента.

> Для работы с DOCX нужна сеть при первом скачивании JSZip с CDN. Интерфейс сайта открывается и работает без этой библиотеки до нажатия кнопки формирования документа.
